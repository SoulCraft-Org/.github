# Support

```mermaid
flowchart LR
  Q[Your question] --> W[A workflow you bought] --> E[Email support with your order number]
  Q --> B[A bug or idea for ComfyUI Base] --> I[An issue on comfyui-base]
  Q --> S[A security problem] --> P[SECURITY.md]
```

| You need | Go here |
|---|---|
| Help with a workflow you bought | support@soulcraft.computer, with your order number. The handbook that ships with the workflow answers most setup questions |
| A bug or idea for ComfyUI Base | An issue on [SoulCraft-Org/comfyui-base](https://github.com/SoulCraft-Org/comfyui-base/issues) |
| A security problem | [SECURITY.md](SECURITY.md) |
